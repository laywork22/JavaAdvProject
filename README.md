# JavaAdvProject
A simple JavaFX quiz game that uses Caesar Cipher.

## Source code
Il codice sorgente si trova nelle directory `GuessTheWordClient` e `GuessTheWordServer`. Per eseguire il codice tramite maven utilizzare il comando `mvn clean compile exec:java`. 

## Javadocs
I Javadocs sono presenti all'interno della cartella `Javadocs`. Per ulteriori informazioni leggere readme.txt all'interno della cartella.

## Executables
Gli esegubili .jar si trovano nella cartella `Esegubili` con tutte le dipendenze e file necessari al loro funzionamento. In tale cartella è presente un readme.txt che contiene informazioni sulle credenziali mockup admin e giocatori da poter utilizzare le due applicazioni.

## Presentation and Design documents
La presentazione powerpoint e le relazioni si trovano rispettivamente nella cartella `Presentazione` e `Relazione di progettazione`.
